# Business Sales & Revenue Prediction System 

An AI-powered web application that predicts future weekly sales using historical business sales data and machine learning.

## Project Overview

The Business Sales Revenue Prediction System uses historical sales information, store and department details, promotional markdowns, holidays, economic factors, and time-based features to predict future weekly sales.

The system provides a complete workflow:

User → Web Application → Flask API → Machine Learning Model → Prediction → SQLite Database → Dashboard

## Features

- Sales prediction using machine learning
- Historical sales visualization

- Store Type
- Store Size

- Month
- Week
- Quarter
- Lag 1
- Lag 2
- Lag 4
- Rolling Mean 4
- Rolling Mean 8

## Machine Learning Models

The system compares:

1. Linear Regression
2. Random Forest Regressor
3. XGBoost Regressor

The models are evaluated using:

- MAE
- RMSE
- R² Score

The model with the lowest MAE and RMSE is selected as the best model.

## Prediction Process

The user enters:

- Store
- Department
- Prediction Date
- Holiday status
- Markdown values

The Flask backend then retrieves historical information for the selected Store and Department and calculates:

- Lag 1
- Lag 2
- Lag 4
- Rolling Mean 4
- Rolling Mean 8

The historical contextual information is also used to construct the model input.

The trained machine learning model then generates the predicted weekly sales.
